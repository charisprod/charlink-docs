<Feedback marginY="16"  variant="info">
All you have to do is update `next-seo.config.js` file.
</Feedback>

```next-seo.config.js
export default {
    openGraph: {
        type: 'website',
        locale: 'en_IE',
        title: 'Your Name',
        url: 'Your Website URL with https',
        description: 'About you.',
        locale: 'en_EN',
        keywords: 'all, keywords, goes, here',
        images: [
            {
                width: 1200,
                height: 630,
                url: '/preview.png',
            },
        ],
        site_name: 'Your Website Name',
    },
    twitter: {
        handle: '@agcrisbp',
        site: 'Your Website URL without https',
        cardType: 'summary_large_image',
    },
};
```

### Favicon

- Create a `favicon.ico` on [convertio.co](https://convertio.co), then put the file into `public` folder.
