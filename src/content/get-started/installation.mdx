- Clone/Fork [this repository](https://github.com/charisprod/charlink) or run the following command to create a new project with this template:

```bash
npx create-next-app@latest app --example https://github.com/charisprod/charlink &&
cd app &&
npm run dev
```

- Open [localhost:3000](http://localhost:3000) with your browser to see the result.

<Feedback marginY="l" variant="info">
Use any editor to work on editing. See: [App To Use](/get-started/app-to-use).
</Feedback>

### Preview

<Feedback marginY="l" variant="warning" description="To avoid failures due to errors or typo, it would be nice to do this step first before deploying to your website."/>

- Build your development.

```bash
npm run build
```

- If there are no issues, everything is ready to deploy.

- Or run the build preview using the following command:

```bash
npm start
```
