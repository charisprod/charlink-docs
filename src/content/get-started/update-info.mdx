### Enable/Disable Social Media
- Find `type: social` and change `on:true|false`.

<Table
  data={{
    headers: [
      { content: "Title", key: "title" },
      { content: "on (default)", key: "on_default" },
    ],
    rows: [
      ["`Twitter`", "`true`"],
      ["`Discord`", "`true`"],
      ["`Instagram`", "`false`"],
      ["`Threads`", "`false`"],
      ["`Medium`", "`false`"],
      ["`Youtube`", "`true`"],
      ["`Github`", "`true`"],
      ["`Linkedin`", "`true`"],
      ["`Email`", "`true`"],
      ["`Post`", "`false`"],
    ],
  }}
/>

<Feedback marginY="16" variant="info">
- Setting `on: true` show the social icon. 
- The social media icons are arranged in a single row at the top of the page below description. If you want to use as list, change type to `type: 'other'`.
</Feedback>

### Add New Social Media Link

- Create a new block by copying this:

<CodeBlock
  codes={[
    {
      language: "js",
      label: "data/LinksData.js",
      code: `{
   title: 'Social Name',
   url: 'https://example.com/',
   type: 'social',
   icon: '/icon.png',
   on: true
}`
    }
  ]}
/>

<Feedback marginY="16" variant="info">
Update all info and make sure to add a `icon.png` file in [public](/get-started/structure-directory) folder.
</Feedback>
